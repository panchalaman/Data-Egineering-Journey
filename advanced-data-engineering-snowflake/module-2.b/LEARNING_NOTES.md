# Module 2.b Reflections: Data Loading & CLI Configurations

This was a very practical, hands-on module focused on moving bulk files around using Snowflake's internal stages and command-line tools.

### What I actually did:
- I used the SnowSQL CLI to push local CSV files (like `sample_orders.csv`) up into Snowflake's internal stages.
- I worked with the 'Tasty Bytes' and 'Weathersource' datasets to simulate loading dimension and fact data.
- I heavily utilized `COPY INTO` commands to rigorously load this data into tables, explicitly handling different file formats and error scenarios.
