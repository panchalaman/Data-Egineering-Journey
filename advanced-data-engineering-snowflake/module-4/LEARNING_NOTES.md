# Module 4 Reflections: Streamlit & Snowflake Native Apps

Snowflake isn't just a database anymore; it's a full-on application platform. This module opened my eyes to building data apps directly where the data lives.

### What I actually did:
- I built a **Streamlit in Snowflake (SiS)** application (`streamlit_weather_hamburg.py`), deploying the UI natively inside Snowflake's infrastructure so the data never has to leave the platform.
- I explored building a **Snowflake Native App** (`hamburg_weather_native_app`), configuring the manifest files, setup scripts, and UI environments to package data and logic into an installable product.
- It really showcased how to deliver actionable insights straight to the end user securely.
