# Module 1.a Reflections: Foundational Transformations & Dashboards

After getting data into Snowflake, I needed to clean it up and show it off. This module was all about transforming raw data and visualizing it.

### What I actually did:
- I wrote the core SQL transformation pipelines (`transformations.sql`) to clean, filter, and structure the raw incoming records.
- I then spun up a quick, interactive Python app using `streamlit.py` to visualize this clean data locally.
- It was incredibly rewarding to immediately connect the dots between raw data, clean SQL transformations, and a front-end dashboard.
